## 📖 О игре

**«Змея и Шарики»** — увлекательная 3D-аркада, в которой вы управляете огненной красной змеёй на волшебной небесной арене. Ваша задача — лопать синие шарики-тучи, прыгая на них, и избегать золотых шариков-ловушек. Успейте набрать **15 очков** за **3 минуты** и получите награду — **Красную Змею**!

---

## 🎮 Правила игры

| Элемент | Действие |
|---------|----------|
| 🔵 **Синий шарик** | ✅ Лопайте! +1 очко |
| 🟡 **Золотой шарик** | ❌ Не трогайте! Штраф −5 секунд |
| 🎯 **Цель** | Лопнуть 15 синих шариков |
| ⏱ **Время** | 3 минуты |
| 🏆 **Награда** | Красная Змея + место на Доске почёта |

---

## 🕹️ Управление

### ⌨️ Клавиатура (ПК)
| Клавиша | Действие |
|---------|----------|
| `←` / `→` | Поворот змеи |
| `↑` / `↓` | Ускорение / Торможение |
| `Пробел` | Прыжок |
| `Мышь` | Вращение камеры (зажать и двигать) |
| `Колёсико` | Приближение / Отдаление |

### 📱 Мобильные устройства
На экране появляются сенсорные кнопки:
- **◀ ▶** — повороты
- **▲ ▼** — ускорение / торможение  
- **⬆** — прыжок (большая золотая кнопка)

---

## ✨ Особенности

- 🌌 **3D-графика** на Three.js с красивым вечерним небом
- 🌳 **Волшебный мир** — деревья, кристаллы, светлячки, облака
- 💦 **Эффекты брызг** при лопании шариков
- 🎊 **Конфетти** при победе
- 🔊 **Звуковые эффекты** (прыжки, лопание, победа)
- 🗣️ **Голосовое сопровождение** (озвучка событий)
- 🌐 **Два языка** — русский и английский
- 📱 **Адаптивность** — работает на телефонах и планшетах
- ⚡ **Оптимизация** — режим низкой детализации для слабых устройств
